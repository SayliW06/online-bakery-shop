# 🧁 Online Bakery Shop

## 📌 About the Project

The **Online Bakery Shop** is a web-based application developed to make it easy for customers to explore bakery products and place orders online. The website offers a user-friendly interface for customers and a separate admin panel for managing the bakery's products, categories, and administrators.

This project was developed using **HTML, CSS, and PHP** to understand web development, user authentication, and administrative management operations.

## ✨ Features

### 👤 User Panel
- User registration and login
- Browse bakery products
- Explore products by category
- View product details
- Place orders for cakes and other bakery products

### 🔐 Admin Panel
- Add, update, and delete administrators
- Manage administrator accounts
- Add, update, and delete product categories
- Manage product categories
- Add, update, and delete bakery products
- Manage the bakery product catalog

## 🛠️ Technologies Used

- **HTML** – Structure of the website
- **CSS** – Styling and page layout
- **PHP** – Server-side logic and application functionality
- **Database** – MySQL workbench

## 🎯 Project Objectives

- Develop an online platform for browsing and ordering bakery products.
- Implement user registration and login functionality.
- Provide an admin panel for managing bakery products and categories.
- Practise frontend development and server-side programming using PHP.
- Understand CRUD operations: Create, Read, Update, and Delete.

## 🚀 How to Run the Project

1. Install a local PHP development environment such as XAMPP.
2. Clone or download this repository.
3. Place the project folder inside the `htdocs` directory of XAMPP.
4. Start Apache and MySQL, if your project uses MySQL.
5. Import the project database into phpMyAdmin if a database is included.
6. Update the database connection settings in the PHP configuration file, if required.
7. Open your browser and visit:

   `http://localhost/online-bakery-shop/`

**Note:** Update the folder name, database setup instructions, and URL according to your actual project structure.
